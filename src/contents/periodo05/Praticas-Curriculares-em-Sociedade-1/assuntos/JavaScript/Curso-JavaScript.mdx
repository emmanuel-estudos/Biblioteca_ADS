# Introdução

Os conceitos básicos da linguagem irão ser apresentados considerando um conhecimento básico prévio sobre programação.

Agora, chegou a hora de aprender a escrever essas receitas usando a língua de um dos robôs mais famosos da internet: o **JavaScript** (ou carinhosamente, **JS**)!

O JavaScript é a linguagem que deixa as páginas da internet divertidas, com botões que funcionam, jogos que rodam no navegador e animações incríveis. Vamos começar pelo básico?
