# Atividade 01 - Contextualização

## Como usar este guia

Este material transforma toda a execução prática da atividade em um roteiro único, limpo e reproduzível. Os comandos foram consolidados para evitar os erros de digitação que surgiram durante a configuração original. 

## Importante

Antes de executar os comandos, personalize os marcadores deste guia. Substitua **SEU NOME** pelo seu nome completo e **seunome** por uma versão em letras minúsculas, sem espaços e sem acentos (exemplo: Maria Silva -> mariasilva). 

Assim, use **www.seunome.com.br**, **site1.seunome.com.br**, **site2.seunome.com.br**, a pasta `/etc/ssl/seunome` e o nome **SEU NOME CA**. Também ajuste o IP `192.168.56.101`, o contêiner `atividade1` e o usuário `ads` caso seu ambiente utilize outros valores. 

## Segurança

Nunca envie ou compartilhe os arquivos ca.key, site1-ca.key e site2-ca.key. Eles são chaves privadas. Para instalar a CA no Windows, copie somente o arquivo ca.crt.

## O que será construído

- Um site Apache com HTTPS e HTTP/2 no domínio www.seunome.com.br.
- Um site Nginx com HTTPS e HTTP/2 no mesmo domínio.
- Dois sites independentes no Nginx: site1 e site2, cada um com certificado próprio.
- Os mesmos dois sites independentes no Apache.
- Uma Autoridade Certificadora própria: SEU NOME CA. 
- Certificados dos dois sites assinados pela CA e reconhecidos como confiáveis pelo Windows e pelo Chrome
