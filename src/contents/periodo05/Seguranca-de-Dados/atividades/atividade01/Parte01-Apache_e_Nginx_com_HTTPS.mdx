# Parte 01

O nome desse tópico é "Apache e Nginx com HTTPS autoassinado, domínio único".

Cada servidor publica uma página **diferente** em https://www.matheus.com.br  com HTTP/2 e redirecionamento de HTTP para
HTTPS. Os prints devem exibir **data** e **hora** — por isso as páginas incluem `$(date)` no conteúdo.
