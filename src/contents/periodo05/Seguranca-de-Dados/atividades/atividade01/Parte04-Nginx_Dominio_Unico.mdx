## Criando Configurações para o Nginx

Abrindo arquivo.

<Terminal>
  <Abas>
    <Aba active>Ubuntu 26s</Aba>
  </Abas>
  <Code>
    <Linha texto="">nano /etc/nginx/sites-available/seunome</Linha>
  </Code>
</Terminal>

```html
server {
    listen 80;
    listen [::]:80;
    server_name www.seunome.com.br;
    return 301 https://www.seunome.com.br$request_uri;
}

server {
    listen 443 ssl http2;
    listen [::]:443 ssl http2;
    server_name www.seunome.com.br;

    root /var/www/nginx;
    index index.html;

    ssl_certificate /etc/ssl/seunome/nginx.crt;
    ssl_certificate_key /etc/ssl/seunome/nginx.key;

    location / {
        try_files $uri $uri/ =404;
    }

    access_log /var/log/nginx/seunome-access.log;
    error_log /var/log/nginx/seunome-error.log;
}
```
