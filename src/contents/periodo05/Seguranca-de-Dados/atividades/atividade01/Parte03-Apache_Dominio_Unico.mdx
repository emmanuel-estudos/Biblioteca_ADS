## Criando Certificado Autoassinado com SAN

<Terminal>
  <Abas>
    <Aba active>Ubuntu 26s</Aba>
  </Abas>
  <Code>
    <Comentario>Criando diretório onde os certificados serão armazenados</Comentario>
    <Linha texto="root@atividade1:/#">mkdir -p /etc/ssl/seunome</Linha>
    <Linha texto="root@atividade1:/#">{`openssl req -x509 -nodes -newkey rsa:2048 -days 365 -keyout /etc/ssl/seunome/apache.key -out /etc/ssl/seunome/apache.crt -subj "/C=BR/ST=Paraiba/L=Cajazeiras/O=IFPB/OU=ADS/CN=www.seunome.com.br" -addext "subjectAltName=DNS:www.seunome.com.br"`}</Linha>
    <Linha texto="root@atividade1:/#">chmod 600 /etc/ssl/seunome/apache.key</Linha>
  </Code>
</Terminal>

## Criando o VirtualHost

Abrindo o arquivo.

<Terminal>
  <Abas>
    <Aba active>Ubuntu 26s</Aba>
  </Abas>
  <Code>
    <Linha texto="root@atividade1:/#">nano /etc/apache2/sites-available/seunome.conf</Linha>
  </Code>
</Terminal>

Use a configuração abaixo:

```html
<VirtualHost *:80>
    ServerName www.seunome.com.br
    Redirect permanent / https://www.seunome.com.br/
</VirtualHost>

<VirtualHost *:443>
    ServerName www.seunome.com.br
    DocumentRoot /var/www/apache

    Protocols h2 http/1.1

    SSLEngine on
    SSLCertificateFile /etc/ssl/seunome/apache.crt
    SSLCertificateKeyFile /etc/ssl/seunome/apache.key

    <Directory /var/www/apache>
        Require all granted
    </Directory>

    ErrorLog ${APACHE_LOG_DIR}/seunome-erro.log
    CustomLog ${APACHE_LOG_DIR}/seunome-access.log combined
</VirtualHost>
```
