# Atividade 03 - Firewall

## Configurações de Rede no VirtualBox

Antes de iniciar as VMs, verifique se suas Interfaces de Rede estão configuradas dessa forma:

- SEED = interface em bridge
- DockerGUI = 1 interface bridge e 1 interface host-Only
- U26s = interface host-Only - verifique se o nome está com **VirtualBox Host-Only Ethernet Adapter**
