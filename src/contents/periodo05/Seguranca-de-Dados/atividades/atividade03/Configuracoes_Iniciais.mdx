# Atv 03 - Configurações Iniciais

## Configurações de Rede no VirtualBox

Antes de iniciar as VMs, verifique se suas Interfaces de Rede estão configuradas dessa forma:

- SEED = interface em bridge
- DockerGUI = 1 interface bridge e 1 interface host-Only
- U26s = interface host-Only - verifique se o nome está com **VirtualBox Host-Only Ethernet Adapter**

## U26s

Faça login.

<Terminal>
  <Abas>
    <Aba active>U26s</Aba>
  </Abas>
  <Code>
    <Comentario>Entrando</Comentario>
    <Linha texto="u26s login">ads</Linha>
    <Linha texto="Password:"> 654123</Linha>
    <Comentario>Verificando IP</Comentario>
    <Linha texto="ads@u26s:~$">ifconfig</Linha>
  </Code>
</Terminal>

Anote o IP referente ao `enp0s3`. Exemplo: `192.168.56.102`.

## SEED1.0

Procure na barra lateral, localizada na esquerda, o quarto item. Este é o terminal dessa máquina.

Ao abrir, descubra o IP. O terminal pode abrir todo em branco ou aparecendo uma mensagem contendo a data de hoje, assim como está abaixo.

<Terminal>
  <Abas>
    <Aba active>SEED 1.0</Aba>
  </Abas>
  <Code>
    <Comentario>Descobrindo IP</Comentario>
    <Linha texto="[data]seed@VM:^$">ifconfig</Linha>
  </Code>
</Terminal>

Pegue o IP referente ao **enp0s3**. Exemplo: `10.3.150.81`.

## DockerGUI

Faça login, se transforme em _SuperUsuário_ e inicie a interface gráfica.

<Terminal>
  <Abas>
    <Aba active>DockerGUI</Aba>
  </Abas>
  <Code>
    <Comentario>Login normal</Comentario>
    <Linha texto="dut login">djr</Linha>
    <Linha texto="Password:">654123</Linha>
    <Comentario>Se transformando em _SuperUsuário_</Comentario>
    <Linha texto="djr@dut:~$">sudo su</Linha>
    <Linha texto="[sudo] password for djr:">654123</Linha>
    <Comentario>Iniciando a interface gráfica</Comentario>
    <Linha texto="root@dut:/home/djr#">startx</Linha>
  </Code>
</Terminal>

Abra o _LXTerminal_ seguindo o caminho: _Menu_ --> _Acessórios_ --> _LXTerminal_.

Crie 3 abas com o comando `Ctrl + Shift + T` e renomei elas para `VM1_INTERNET`, `VM2_GATEWAY`, `VM3_LOCAL_INTERNET`.

Os números das VMs não importa. O importante é saber qual se refere a Internet, Gateway e Internet Local.
