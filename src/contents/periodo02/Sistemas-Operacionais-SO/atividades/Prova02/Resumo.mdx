# Resumo para a Prova 02

## Resumo Global (Arquivos 04 ao 08)

Em conjunto, esses arquivos fornecem uma visão abrangente sobre como o hardware de um computador e o software do Sistema Operacional se integram para gerenciar recursos de forma eficiente e segura.

O fundamento reside na arquitetura física (Von Neumann ou Harvard), onde a CPU (composta por UC, ULA e Registradores) se comunica com a memória e periféricos através de barramentos sincronizados por um clock. Para que essa comunicação não torne o sistema lento, utilizam-se mecanismos como interrupções e DMA, que liberam o processador de esperas desnecessárias por dispositivos externos.

A segurança e estabilidade do sistema são garantidas pela separação rígida de privilégios controlada pelo hardware. O Modo Núcleo detém o controle total, enquanto as aplicações operam no Modo Usuário, sendo confinadas em suas áreas de memória pela MMU. Qualquer necessidade de acesso ao hardware por uma aplicação deve ser solicitada formalmente através de uma System Call, que utiliza mecanismos de trap (interrupção de software) para transitar entre os níveis de privilégio.

Por fim, o Sistema Operacional estrutura seu núcleo de diferentes formas (Monolítico, em Camadas, Micronúcleo ou Híbrido) para equilibrar desempenho, robustez e flexibilidade. Essa organização define como os drivers, utilitários e o próprio kernel irão interagir para abstrair a complexidade do hardware e oferecer serviços estáveis aos usuários.
