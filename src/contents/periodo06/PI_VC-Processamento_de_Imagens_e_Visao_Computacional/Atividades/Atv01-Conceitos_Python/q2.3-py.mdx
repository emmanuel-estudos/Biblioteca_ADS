# Atividade 2.3

## Enunciado

Uma "linha" de uma imagem em tons de cinza é dada pela lista linha. Usando apenas fatiamento e list comprehension:

- obtenha a linha espelhada;
- obtenha uma versão subamostrada (um pixel sim, outro não);
- obtenha a versão limiarizada: 255 se o valor for maior que 100, senão 0.

```py
linha = [12, 40, 90, 130, 180, 220, 250, 200, 150, 60]

espelhada = None      # SEU CÓDIGO AQUI
subamostrada = None   # SEU CÓDIGO AQUI
limiarizada = None    # SEU CÓDIGO AQUI

print(espelhada, subamostrada, limiarizada, sep="\n")
```

## Resolução

```py
linha = [12, 40, 90, 130, 180, 220, 250, 200, 150, 60]

espelhada = linha[::-1]
subamostrada = linha[::1]
limiarizada = [255 if valor > 100 else 0 for valor in linha]

print(espelhada, subamostrada, limiarizada, sep="\n")
```
